Política de privacidad — Js TV Remote

Última actualización: 4 de septiembre de 2026

1. Qué hace la aplicación

Js TV Remote permite descubrir y controlar televisores compatibles que se encuentran en la misma red local WiFi que el teléfono. La comunicación con el televisor se realiza directamente entre el teléfono y el dispositivo local.

2. Datos de red y dispositivos

Para encontrar y controlar televisores, la aplicación utiliza la dirección IP local y protocolos de red como SSDP, HTTP y WebSocket. Estos datos se utilizan para realizar la función principal de control remoto y no se envían a un servidor propio de Js.

3. Publicidad

La aplicación utiliza Google Mobile Ads (AdMob) para mostrar anuncios. El SDK de Google puede recopilar y compartir información como dirección IP, interacciones con la aplicación, información de diagnóstico y determinados identificadores del dispositivo para publicidad, análisis y prevención de fraude. El tratamiento depende de la configuración de AdMob y de las opciones de consentimiento del usuario.

4. Consentimiento

Cuando corresponda, la aplicación utiliza Google User Messaging Platform para solicitar y gestionar las opciones de privacidad y consentimiento antes de solicitar anuncios.

5. Servicios externos

Los anuncios son proporcionados por Google. La aplicación también puede abrir sitios externos, como Instagram y otras herramientas web, cuando el usuario selecciona esos enlaces.

6. Seguridad

La aplicación no mantiene una cuenta de usuario ni un servidor propio para almacenar información de los televisores. Las conexiones de publicidad gestionadas por Google utilizan las medidas de seguridad de sus servicios.

8. Cambios

Esta política puede actualizarse cuando cambien las funciones de la aplicación, sus proveedores o los requisitos legales.
